# 麦轮小车上位机（优雅黑）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用

1. 左侧选择串口：当前联调用 **COM5（USB转串口，115200）**；蓝牙修好后可改 COM8/COM7；点“连接”；
   > 主固件已开启“调试串口协议桥”，所以 COM5 也能直接跑上位机协议（115200）。
2. 没有硬件时勾选“演示模式（无硬件）”再点连接，可直接看界面和曲线；
3. “手动遥控”页：拖动虚拟摇杆，或用键盘 WASD 移动、Q/E 原地旋转、空格急停；
   > 固件已加入最小驱动速度 0.3（归一化），低于该值会自动放大到 0.3，避免电机低速震动。
4. “固定路线”页：设置正方形边长，点“开始”；
5. “PID调参”页：设置位置环 PID 和限幅，点“下发参数”；
6. “数据曲线”页：实时看四轮目标/实际速度；
7. “固定路线”已实现：前进 -> 停顿 -> 左转90° -> 停顿 -> 重复4次，可设边长/速度/停顿；
8. “PID调参”页新增“速度平滑（加速度限制）”，可下发线/角加速度，避免急起急停；
9. 桌面已创建快捷方式“麦轮小车上位机”；
10. 自动驾驶/避障/视觉为预留 Tab。

```text
│  └─ curve_panel.py  实时曲线

```
