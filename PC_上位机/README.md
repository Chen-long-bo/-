# 麦轮小车上位机（优雅黑）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 当前功能

1. 左侧选择串口：
   - 蓝牙 SPP 使用“传出”端口，当前为 `COM7`，波特率 `9600`；
   - `COM4` 是“传入”端口，通常不要在上位机里作为客户端打开；
   - 有线调试可用 USB 转串口，按 `config.py` 的端口和波特率配置。
2. “手动遥控”页：
   - 前进、后退、左移、右移按键；
   - 按住移动，松开立即停止；
   - 共用“平移速度”滑块；
   - WASD 保留；
   - 输入旋转角度后可按左/右转，支持 45°/90° 快捷按钮；
   - 普通遥控不使用 PID，也不使用缓起缓停。
3. “固定路线”页：
   - 正方形路线；
   - 直接速度控制，不使用 PID 和缓起缓停。
4. “控制与测试”页：
   - Kp、Ki、Kd 参数；
   - 正负目标距离，正数前进、负数后退；
   - 只有本页开始 PID 位置控制时使用 PID；
   - 曲线显示目标位置、实际位置、误差、四轮目标/实际速度。
5. “参数调节”页：
   - 78 项参数说明与搜索；
   - 运行期 PID/限幅参数下发；
   - 编译期参数只读提示；
   - 待确认假设清单。
6. 数据曲线、调试中心、日志和预留 Tab 保留。

## 文件结构

```text
├─ parameter_guide.json 参数说明数据
├─ widgets/
│  └─ curve_panel.py    四轮速度 + 位置/误差曲线
└─ ui/

```
